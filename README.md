# Gyors hibajelentés – bemutató

Az 1. csapat bemutatója az **E.ON × Corvinus UX/UI Design Day** szerelői app kihívására.

Élő változat: https://bertagabor9283.github.io/eonapppresentation/

Az app: https://szbaliint.github.io/eon-szerelo-app/

## Vezérlés

| Billentyű | Funkció |
|---|---|
| ← → / Szóköz | Lapozás |
| N | Beszédjegyzet (ki beszél, mit mond) |
| F | Teljes képernyő |
| E | Szerkesztő mód (a szöveg a böngészőben mentődik) |

Egyetlen önálló HTML-fájl, build nélkül. Minden cím, név és munkalapszám fiktív.
